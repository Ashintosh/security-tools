# Tool Index

## Email Analysis
- [Google Message Header Analyzer](categories/email-analysis/google-message-header-analyzer.md) – Parse email headers, trace routing, SPF/DKIM/DMARC checks.
- [Microsoft Message Header Analyzer](categories/email-analysis/microsoft-message-header-analyzer.md) - Parse and visualize email headers, including routing and authentication results.
- [Mailheader.org](categories/email-analysis/mailheader-org.md) – Quick email header decoding and relay path visualization.
- [PhishTool](categories/email-analysis/phishtool.md) – Phishing investigation platform, extract indicators from emails.
- [eml_analyzer](categories/email-analysis/eml-analyzer.md) – CLI tool to parse .eml files and extract URLs, attachments, headers.

## URL & Web Analysis
- [URLScan.io](categories/url-analysis/urlscan-io.md) – Execute and analyze URLs in a sandboxed environment.
- [Wannabrowser](categories/url-analysis/wannabrowser.md) – Browser emulation to observe website behavior.
- [URL2PNG](categories/url-analysis/url2png.md) – Generate screenshots of web pages.
- [URL Extractor](categories/url-analysis/url-extractor.md) – Extract URLs from text or documents.

## IP & Domain Reputation
- [Cisco Talos Reputation](categories/ip-domain-reputation/cisco-talos-reputation.md) - IP and domain reputation lookup based on global threat intelligence.
- [MXToolbox](categories/ip-domain-reputation/mxtoolbox.md) – DNS, blacklist, and mail server checks.
- [ipinfo.io](categories/ip-domain-reputation/ipinfo.md) – Geolocation, ASN, ISP, and organization info.
- [Spamhaus](categories/ip-domain-reputation/spamhaus.md) – Threat intelligence and blocklist lookup.

## Malware Analysis
- [Cisco Talos File Reputation](categories/malware-analysis/cisco-talos-file-reputation.md) - File hash reputation lookup using Cisco Talos threat intelligence.
- [VirusTotal](categories/malware-analysis/virustotal.md) – Aggregated AV and threat intelligence for files, hashes, URLs.
- [Hybrid Analysis](categories/malware-analysis/hybrid-analysis.md) – Malware sandbox with static and dynamic analysis.
- [Any.Run](categories/malware-analysis/any-run.md) – Interactive sandbox for live malware execution.
- [Joe Security](categories/malware-analysis/joe-security.md) – Advanced sandbox with detailed forensic reports.

## Data Transformation
- [CyberChef](categories/data-transformation/cyberchef.md) – Decode, parse, and transform data (Base64, hashes, URLs, etc.)
