## Description
PhishTool is a phishing investigation and response platform designed to analyze suspected phishing emails, extract indicators, and assist with incident response workflows. It supports both manual analysis and collaboration across security teams.

## Common Use Cases
- Analyze reported phishing emails
- Extract indicators such as URLs, IPs, domains, and attachments
- Assess sender authenticity and email metadata
- Document and manage phishing investigation
- Support user-reported phishing workflows

## Strengths
- Centralized platform for phishing investigation
- Automatic extraction of indicators from emails
- Case management and collaboration features
- Integrates with threat intelligence sources

## Limitations
- Account required to use the platform
- Some advanced features require paid tiers
- Less suitable for low-level, manual header-only analysis
