---

## Description
Parses email headers to present a readable breakdown of mail flow, sending servers, and authentication results (SPF, DKIM, DMARC).

## Common Use Cases
- Analyze suspicious emails for phishing or spoofing
- Trace email delivery paths
- Review SPF, DKIM, DMARC results

## Strengths
- Fast and easy to use
- Visual layout is clean
- Helps quickly identify anomalies in mail routing

## Limitations
- Focused on single-message analysis (not bulk)
- No automation for large-scale investigations
