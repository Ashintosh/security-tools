## Description
eml_analyzer is a Python-based tool for parsing `.eml` and `.msg` email files. It extracts headers, attachments, URLs, and other metadata, making it well-suited for programmatic email analysis and automation workflows.

## Common Use Cases
- Extract email headers, sender info, and routing paths from `.eml` and `.msg` files
- Identify URLs, domains, and IPs contained in emails
- Analyze attachments and file metadata
- Automate processing of large sets of email files

## Strengths
- Handles raw `.eml` and `.msg` files from any email provider
- Can be integrated into scripts for automated analysis
- Supports extraction of multiple indicators from a single email
- Lightweight and open-source

## Limitations
- Does not perform live URL or attachment sandboxing
